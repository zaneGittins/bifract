# Exchange

Datasets, lookups, detections, models, saved searches, dashboards, normalizers and alert policies, shared for every Bifract install. Bundles group the pieces of one use case so you can add them together.

To add one, open **Exchange** in Bifract's sidebar (under **Data**) and click **Add**. See [Using the Exchange](using.md) for what each kind adds and how to contribute.
