# Welcome to Bifract

Bifract is a self-hosted, open source SIEM built on ClickHouse. It adds process provenance graphs, behavioral baselines, and collaborative investigation to fast log search, all on your own infrastructure.

## Where to Start

- **New to Bifract?** Start with [Installation](getting-started/installation.md), then [Navigating Bifract](getting-started/navigation.md)
- **Deploying on Kubernetes?** See [Kubernetes](getting-started/kubernetes.md) and [Sizing Guide](getting-started/sizing.md)
- **Sending logs?** See [Ingestion](ingestion/overview.md)
- **Writing queries?** Learn [BQL basics](bql/basics.md)
- **Setting up alerts?** Read [Alerting](alerting/alerts.md)
- **API integration?** Jump to the [API Reference](api/authentication.md)
