# Welcome to Bifract

Bifract is a self-hosted, open source SIEM built on ClickHouse. It adds process provenance graphs, behavioral baselines and collaborative investigation to fast log search, on your own infrastructure.

## Where to start

- **New to Bifract?** [Install it](getting-started/installation.md), then read [Navigating Bifract](getting-started/navigation.md).
- **Deploying on Kubernetes?** See [Kubernetes](getting-started/kubernetes.md) and the [Sizing Guide](getting-started/sizing.md).
- **Sending logs?** See [Ingestion](ingestion/overview.md).
- **Writing queries?** Learn [BQL basics](bql/basics.md).
- **Setting up alerts?** Read [Alerting](alerting/alerts.md).
- **Integrating over the API?** Go to the [API Reference](api/authentication.md).
